# 23 · 판매 설정을 판매가 계산기에 맞춘다 (2026-10-12)

보갬: "주문관리는 사실상 필요하지 않은 것 같고, 매출연동은 검색구매 · 광고구매 따로 나누지 말고, 전환율을 1~30%까지 내가 조정할 수 있게.
수수료는 판매가 계산기를 넣었으니 이 수수료대로 적용하고, 엑셀에서 활용할 수 있는 것이 있으면 반영하자. 네이버 6.6% 쯤, 쿠팡 11.66% 쯤."

## 계산기 엑셀에서 읽은 것 (밤4종 판매가 계산기 v1.6, 기준일 2026-10-08)

| 설정_원가 탭 | 값 | 화면에서 |
|---|---|---|
| 네이버 수수료율 | **6.63%** | 네이버 수수료 % 칸의 기본값 |
| 쿠팡 수수료율 | **11.66%** | 쿠팡 수수료 % 칸의 기본값 (쿠폰 적용가에 붙는다) |
| 광고 안전계수 | 네이버 1.0 · 쿠팡 1.1 | 손익분기 전환율 · 최소 ROAS · 감당 CPC 의 곱수 (전부터 같은 값이었다) |
| 목표 ROAS | 채널별 | 설정 줄 끝에 "최소 ROAS ○ (목표 ○ 안 / 초과)" 로 맞대 보여 준다 |
| 쿠팡 쿠폰액 | 계산기 값 | 쿠팡의 판매가 = 쿠폰 적용가 (등록가 − 쿠폰) |
| 최소 공헌이익 | 계산기 값 | 마진이 이보다 작으면 설정 줄에 "최소 공헌이익 ○원 미달" |
| 공급가 안전가산 | 계산기 값 | 총원가에 이미 들어 있다. 화면은 총원가를 공급가 칸에 넣는다 |
| 옵션 원장 | 19개 (사용여부 Y) | "계산기" 고르는 칸. 고르면 총원가 · 그 채널 판매가 · 수수료가 들어간다 |

계산식은 계산기와 같다.

```
공헌이익(마진) = 판매가 × (1 − 수수료율) − 총원가
최소 ROAS      = 광고 안전계수 × 판매가 ÷ 공헌이익
손익분기 전환율 = 클릭 단가 × 광고 안전계수 ÷ 공헌이익
```

19개 옵션 전부에서 화면 식으로 다시 낸 공헌이익 · 최소 ROAS 가 엑셀 값과 같다 (네이버 · 쿠팡 모두. 오차 1원 · 0.01 안).
(원가 · 마진 숫자는 공개 저장소라 여기에 적지 않는다.)

## 화면에서 바뀐 것

- **주문관리 · 매출연동 고르는 칸을 없앴다.** 네이버 수수료 % 한 칸(6.63)만 남는다. 숫자는 직접 고칠 수 있다.
  전에는 주문관리 3.63% + 매출연동 3% = 6.63% 가 기본이었으니 기본값은 그대로고, 고르는 단계만 사라졌다.
- **목표 전환율 슬라이더 1~10% → 1~30%** (0.5% 단위). 마진 × 전환율 표도 1 · 2 · 3 · 5 · 10 · 15 · 20 · 30% 로 바꿨다.
- **쿠팡 판매가가 틀려 있었다.** 계산기 옵션을 쿠팡으로 넣으면 등록가(쿠폰 적용가 + 쿠폰액)를 판매가로 써서 마진이 쿠폰액 × (1 − 수수료율) 만큼 크게 나왔다.
  쿠폰 적용가로 바로잡았다. 채널 단추를 누르면 고른 옵션의 판매가도 그 채널 값으로 바뀐다.
- **엑셀의 작은 수를 100배로 읽는 버그.** 엑셀은 0.0663 을 `6.6299999999999998E-2` 로 적는다. 글자를 걷어내는 숫자 읽기가 이를 6.63 으로 읽었다. 지수 표기를 먼저 본다.
- 엑셀 분석 탭의 계산기 표: 설정 한 줄 + 쿠팡 쿠폰 적용가 · 쿠팡 최소 ROAS 열.
- 처음 여는 브라우저면 계산기의 기준 옵션이 들어가 있다. 전에 남긴 설정이 있으면 공급가 · 판매가는 그대로 두고 수수료만 바뀐다.
- 고른 옵션과 직접 고친 수수료는 브라우저에 남는다.

## 연관 목록: "살 사람 있는 것만" 단추

네이버 목록에는 식품이 아닌 것 · 정보성 키워드가 섞여 온다 (docs/22). 보갬: "구매의도 필터로 거르는 것 굿 아이디어."
연관 표시줄에 단추를 하나 뒀다. 누르면 구매의도 없음 · 미확인이 빠진다 (필터의 구매의도 "낮음 이상" 과 같다). 밤 125 → 75 · 한우 950 → 548.
미확인(쇼핑 클릭 지수를 아직 못 받은 것)도 같이 빠진다는 점은 알고 써야 한다.

## 저장된 화면에 계산기를 싣는 법

- PC 실시간: `넣는곳\공급가표·계산기` 에 엑셀을 두면 열 때 읽는다 (계산기 엑셀을 복사해 두었다).
- 저장된 화면(claude.ai): `node build-calc.mjs` → `app\data-calc.js`. 화면과 같은 `xlsx-lab.js` 로 읽는다.
- **`data-calc.js` 는 원가 · 공급처가 들어 있어 공개 저장소에 올리지 않는다.** 저장소 · 배포 zip 에는 빈 파일(`window.CALCRECS=[];`)만 둔다. `data-is.js` 와 같은 규칙.
- 계산기를 고치면 `넣는곳` 의 파일을 바꿔 넣고 `build-calc.mjs` 를 다시 돌린 뒤 페이지를 다시 올린다.
