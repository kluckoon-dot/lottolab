### 약관 주의 (2026-09-07 시행 / API 허브 2026-09-20 적용)

검색 API 특약 개정으로 금지된 것:

- 데이터 복사·저장·캐싱
- 제3자 제공·판매
- AI 입력·학습·개선·평가·노출 활용
- 검색 결과 표시 페이지 광고 게재, **API 활용 수익화**
- 순위·내용 수정·변조·왜곡, 결과 앞뒤에 다른 내용 삽입

허용 보관 기간:
- 사용자 기기: 24시간 또는 새 질의 시점 중 **짧은 쪽**
- 서버: 이력 조회 목적 **최대 21일**

의무:
- 가공 없이 노출, 출처 표시, 원본 이동 링크 제공

> 적용 범위가 검색어트렌드·쇼핑인사이트까지인지는 **원문 확인 필요**.
> 검색광고 API는 별개 서비스로 이 특약 대상이 아니다.

|---|---|:--:|---|

| 공공데이터포털 aT | 일별 도소매 가격, 공판장 가격, 월별 소매가격 | 미착수 | KAMIS와 중복·보완 |

### KAMIS 커버리지

- 도매: 5개 도시 16개 시장 / 69품목 116품종
- 소매: 19개 도시 54개 시장 / 90품목 143품종
- 등급 2단계, 1996년~현재 일별
- 주말·공휴일 제외 매일 조사

**용도:** 사라진 "평균가격" 카드를 시장 표본 평균이 아닌 **실거래 시세**로 대체.
농산물 kg 단가 혼재 문제(1kg/5kg)도 규격·등급 분리로 해결됨.

## 공급사 계열

| 소스 | 주는 것 | 상태 | 비고 |
|---|---|:--:|---|
| 온그린 (어드민플러스 Seller Open API) | 공급가, 옵션, 재고, 발주, 배송추적, 예치금 결제 | **Access Key 0개 — 미검증** | 분당 60회 / 일 10,000회 |

**미검증이라는 뜻:** 기능표는 문서 기반 추정이다. 실호출 1회 전까지 설계 확정 금지.

실호출로 반드시 확인할 것:
1. 부여된 실제 권한 범위 (업체마다 다름)
2. 옵션별 추가금 계산 방식
3. 묶음배송 계산 방식
4. 과세/면세 구분 필드
5. 결제 등록 권한 유무 (문서 표기 불명확)

**안 되는 것으로 확인된 것:** 카드 자동결제, 취소·반품·교환 실행, 상품·공급가 수정

## 목표 구조 — 3단 비교

```
KAMIS 도매 실거래 시세  ─┐
                         ├─→  마진 계산 · 매입 판단
온그린 공급가           ─┘

네이버 검색광고 지표    ─→  수요 판단 (검색량 · 클릭 · 입찰가)

자사 스마트스토어 판매가 ─→  현재 포지션
```

이 구조의 장점: 축 3개가 **서로 다른 기관**에서 온다.
네이버 하나가 막혀도 전체가 무너지지 않는다.
지금 설계(네이버 단일 의존)의 가장 큰 약점이 이거다.
