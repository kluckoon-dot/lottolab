# 아이템스카우트와 우리 수치 대조

2026-09-14 · 사용자가 올린 아이템스카우트 "고구마 연관키워드" PDF(49개) 기준

## 1. 검색수 — 문제 없다

같은 키워드 29개를 맞대어 보았다.

| 키워드 | 아이템스카우트 | 우리 | 차이 |
|---|---|---|---|
| 김의준고구마 | 13,110 | 12,870 | -2% |
| 해남고구마 | 5,890 | 5,530 | -6% |
| 토울고구마 | 4,040 | 3,980 | -1% |
| 해들녘고구마 | 1,360 | 1,360 | 0% |
| 강화도고구마 | 710 | 710 | 0% |

**29개 중 27개가 오차 10% 이내, 차이 중앙값 0.0%.**
남은 차이는 수집 날짜가 달라서다. 둘 다 같은 네이버 검색광고 API 를 쓴다.

## 2. 경쟁강도 — 아예 다른 지표다

PDF 에서 공식을 역산했다.

```
경쟁강도 = 상품수 ÷ 검색수
```

48개 전부 이 식과 일치했다(100%).

| 키워드 | 상품수 | 검색수 | 계산 | 표기 |
|---|---|---|---|---|
| 김의준고구마 | 386 | 13,110 | 0.029 | 0.03 |
| 해남고구마 | 5,061 | 5,890 | 0.859 | 0.86 |
| 토울고구마 | 741 | 4,040 | 0.183 | 0.18 |

우리 경쟁강도는 전혀 다른 것이다.

```
우리 = 0.55 × (광고깊이/15) + 0.45 × (1위입찰가/2500),  0~10 으로 환산
```

**상품수 원본이 없어서 만든 대용품이다.** 쇼핑검색 API 가 2026-07-31 종료됐다.
값의 크기도 뜻도 다르므로 아이템스카우트 수치와 나란히 놓고 비교하면 안 된다.

## 3. 의도 분류 — 우리 분류는 맞았다

아이템스카우트가 쇼핑성이라 한 29개를 우리도 **29개 전부 쇼핑성**으로 봤다.
우리 고구마 키워드 412개 중 402개가 쇼핑성이다.

"정보성처럼 보인다"는 인상의 실제 원인은 분류가 아니라 **정렬**이다.
검색량 순으로 세우면 요리 키워드가 위로 온다.

```
고구마줄기볶음 116,440   고구마줄기김치 55,300   고구마순김치 45,590
고구마순볶음 35,050      고구마맛탕 14,140      고구마에어프라이어 14,530
```

아이템스카우트 목록에는 이것들이 없다. 그쪽은 **대표카테고리:고구마** 로 걸렀기 때문이다.
대표카테고리는 그 키워드로 실제로 팔리는 상품의 카테고리이고, 쇼핑 검색 결과를 봐야 안다.
우리는 그 데이터가 없어 키워드 글자로만 묶는다. 그래서 요리 키워드가 같이 들어온다.

광고 신호로 가를 수 있는지도 재보았다. 안 된다.

```
아이템스카우트 쇼핑성 29개   광고깊이 7.03 · 1위입찰가 2,325원 · 입찰가있음 100%
요리 어미 968개              광고깊이 6.08 · 1위입찰가 1,236원 · 입찰가있음  91%
```

고구마줄기볶음도 광고깊이 7 에 입찰가 400원이다. 광고주가 레시피 키워드에도 붙는다.

## 4. 그래서 막힌 곳은 하나다 — 상품수

상품수만 있으면 세 가지가 한 번에 풀린다.

1. 경쟁강도를 아이템스카우트와 같은 식으로 계산
2. 대표카테고리 추정 (상품이 몰린 카테고리)
3. 요리 키워드 걸러내기 (상품수가 검색수에 비해 터무니없이 적은 것)

쇼핑검색 API 가 종료됐지만 API HUB 로 이관됐을 가능성이 남아 있다.
검색어트렌드가 `/search-trend/v1/search`, 쇼핑인사이트가 `/shopping/v1/...` 로 살아 있었다.
