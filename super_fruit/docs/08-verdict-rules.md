## 고친 것 ① 황금점수 공식의 치명적 버그

기존 공식은 이랬다.

```
황금점수 = (log10(월검색수) − 3) ÷ (경쟁 + 0.25) × 26
```

`log10(검색) − 3`은 **검색 1,000에서 0이 되고 그 아래는 음수**다.

| 월 검색수 | log10 − 3 | 결과 |
|---:|---:|---|
| 100 | −1.00 | **0점** |
| 300 | −0.52 | **0점** |
| 1,000 | 0.00 | 0점 |
| 10,000 | 1.00 | 정상 |

**검색 1,000 미만 10,958개(80.2%)가 전부 0점이었다.**
사용자가 "월 100이면 가치 있다"고 한 구간을 공식이 통째로 죽이고 있었다.

수정:

```
수요 = clamp( log10(월검색수 / 100) / 2 , 0 , 1.5 )      // 100에서 0, 10만에서 1.5
경쟁 = 광고깊이/15 × 0.55 + 1위입찰가/2500 × 0.45
광고감당 = clamp( 목표 전환율 ÷ 손익분기 전환율 , 0 , 1 )
황금점수 = 수요 ÷ (경쟁 + 0.2) × 26 × (0.5 + 0.5 × 광고감당)
```

## 고친 것 ② 판정을 점수 문턱이 아니라 조건 통과로

"황금점수 55점 이상"은 데이터 분포가 바뀌면 의미가 흔들린다.
사용자 기준을 그대로 판정으로 쓰는 편이 정직하다.

```
패스    월 검색 < 100                          → 볼 가치 없음
패스    마진율 < 20%                           → 사용자가 절대 안 된다고 한 선
린정    광고 감당 O  AND  경쟁강도 ≤ 5.0
반린정  둘 중 하나만 충족
패스    둘 다 미달
```

**황금점수는 판정에 쓰지 않고 줄 세우기에만 쓴다.**

## 전환율 — 두 지표를 섞지 않는다

사용자가 "네이버는 클릭율 0.5%, 쿠팡은 0.1%" 라고 했는데,
**클릭률(CTR)과 전환율(CVR)은 다른 지표다.**

- **클릭률** = 노출 대비 클릭. 광고가 눈에 띄는가
- **전환율** = 클릭 대비 구매. 들어와서 사는가

손익분기 계산에 들어가는 것은 **전환율**이다.

```
손익분기 전환율 = CPC × 배수 ÷ 마진
감당 가능 CPC   = 마진 × 목표 전환율 ÷ 배수
```

마진 6,431원 기준으로 계산하면 이렇다.

마진 6,431원(홍로사과 2kg) 기준 · 실측한 3위 모바일 입찰가 분포로 계산했다.

| 전환율 | 감당 CPC 상한 | 광고 되는 키워드 | 린정 |
|---|---:|---:|---:|
| **1%** (기본) | 64원 | **0개** | 0개 |
| 3% | 193원 | 3,211개 | 1,102개 |
| 5% | 322원 | 5,244개 | 1,996개 |
| 8% | 514원 | 8,016개 | 3,307개 |
| **10%** (최대) | 643원 | 9,353개 | 3,982개 |
| 참고 · 0.5% | 32원 | 0개 | — |
| 참고 · 0.1% | 6원 | 0개 | — |

**전환율 0.5%로는 광고가 수학적으로 불가능하다.** 3위 입찰가 최저가가 70원인데 감당 상한이 32원이다.
그래서 0.5% / 0.1%는 **판정 기준이 아니라 화면의 참고선**으로만 표시한다.

### 슬라이더 범위를 10%까지 연 이유

취급 품목이 제철 과일·채소에 몰려 있다. 이 카테고리는
**목적성 구매 비중이 높아 전환율이 평균보다 높게 나오는 편**이고,
제철 시즌의 세부 키워드에서는 두 자릿수도 나온다고 알려져 있다. → 확인 필요

그래서 보수(1%)부터 공격(10%)까지 한 화면에서 왔다갔다 하며
**"어느 전환율부터 이 키워드가 광고로 남는가"** 를 직접 보게 한다.

> 이 수치는 업계 통설이며 우리 스토어 실적으로 검증된 값이 아니다.
> 실제 전환율이 확인되면 그 값을 기본값으로 바꾼다. `docs/05` 의 피드백 루프가 이 자리를 메운다.

## 수집기는 바꿀 필요가 없다

**판정 기준을 바꿔도 재수집은 필요 없다.**

수집기는 원본 지표만 모은다 — 월검색수 · 클릭 · CTR · 경쟁도 · 입찰가.
황금점수 · 손익분기 전환율 · 의도 분류 · 판정은 **전부 화면에서 계산**한다.

그래서 기준이 바뀔 때마다 다시 긁지 않는다. 화면에서 슬라이더만 움직이면 된다.
