# 38 · 태그 후보 = 네이버 태그사전에 있는 것만 (2026-11-27)

보갬: "키워드랩에서 후보로 지정해주는것이 실제로 네이버에 적용되지 않는 태그들이 많아서 내가 또 일일이 작성해야 하는 불편함이 있거든?"

## 왜 생겼나

- 스마트스토어는 **네이버 태그사전에 등록된 태그만** 검색에 반영한다. 사전 목록은 공개돼 있지 않다.
- 상품명 만들기의 태그 후보는 검색광고 키워드를 그대로 썼다. 그래서 반영 안 되는 태그가 섞였다.
  - 표기가 다른 것: 키워드도구는 `절임배추10KG`를 주는데, 사전에는 `절임배추10kg`로 있다.
  - 사전에 없는 말: `절임배추가격` · `절임배추추천` · `농협절임배추` · `무농약절임배추` …
- 11/27 보갬이 절임배추 태그 10개를 넣었을 때 검색에 반영된 것은 3개였다(검색품질 체크).

## 네이버 커머스API (2.91.0, 공식 문서)

| 기능 | 주소 | 받는 것 |
|---|---|---|
| 토큰 | `POST /external/v1/oauth2/token` | client_id · timestamp · client_secret_sign · grant_type=client_credentials · type=SELF |
| 추천 태그 검색 | `GET /external/v2/tags/recommend-tags?keyword=` | `[{code, text}]` |
| 제한 태그 여부 | `GET /external/v2/tags/restricted-tags?tags=a,b,…` | `[{tag, restricted}]` |

- **토큰**: 서명은 bcrypt(`client_id_timestamp`, salt = 시크릿)를 base64로 만든다. 유효 시간은 3시간이다.
- **추천 태그 검색**: 그 말로 **시작하는** 사전 태그를 **20개까지** 준다.
  - 대소문자와 띄어쓰기는 가리지 않는다(`절임배추10KG` → `절임배추10kg`).
- **제한 태그 여부**: 한 번에 50개까지 묻는다. 100개는 "파라미터 개수 초과"로 거부된다.
  - 제한으로 나온 것: 네이버 · 쿠팡 · 스마트스토어 · 세일 · 남의 상표 · 담배 · 성인용품, 그리고 샤인머스캣.
- **요청량**: 초당 2번, 버스트 4(응답 헤더 `GNCP-GW-RateLimit-*`).
- **막히는 경우**:
  - 애플리케이션에 API 호출 IP를 정해 두었으면, 이 PC의 IP가 빠졌을 때 403 `GW.IP_NOT_ALLOWED`가 난다.
  - 애플리케이션 API 그룹에 상품이 없으면 403이 난다.

### 미리 맞혀 봄

## 붙인 것

- **`fetch-tags.mjs`**: 매일 수집 단계, 마지막 화면 파일 다음 · pack-z 앞. 하루 7,000회까지, 약 1시간.
  - 묻는 차례: 품목 이름(sections.json terms) → 섹션 키워드(검색 많은 순) → 섹션 밖 사전(검색 300↑) → 제한 태그.
  - **20개 미만으로 온 말이면** 그 말로 시작하는 사전 태그가 다 온 것이다. 그 말로 시작하는 키워드는 묻지 않고 판정한다.
    - 호출 60번에 섹션 키워드 1,137개가 판정됐다.
    - 앞부분으로 판정한 40개를 직접 물어 확인했다. 40개 모두 같았다.
  - 결과 저장
    - `naver-out/tags-dict.json`에 쌓인다. 멈춰도 다음 회차가 이어받는다.
    - 30일 지난 것은 다시 묻는다.
    - 화면용 파일은 `app/data-tags.js`다(`window.KWTAGS = { at, has, full, part, rx }`).
  - 서명은 `vendor/bcryptjs`(bcryptjs 2.4.3, MIT)로 만든다.
  - 키는 key.txt C 칸(`NAVER_COMMERCE_ID` · `NAVER_COMMERCE_SECRET`)에서 읽는다. 비어 있으면 이 단계만 건너뛴다.
- **화면 `keyword-lab.js` (상품명 만들기)**
  - 태그 후보 채우는 차례(최대 10개):
    1. 사전에 있는 태그 — 상품명이 못 덮은 키워드부터, 그다음 덮은 키워드.
    2. 아직 확인 못 한 키워드 — 점선으로 표시.
  - 표기는 사전 그대로 쓴다. 같은 태그는 하나만 남긴다.
  - **뺀 키워드** 줄을 새로 둔다. 사전에 없거나 제한 태그인 키워드를 취소선으로 보여 준다.
  - 태그 복사도 사전 표기로 복사된다.
- **`publish-plan.mjs`**: `data-tags.js`가 있으면 저장본에 올린다.
- **`5 매일 수집.bat`**: 태그사전 단계를 넣었다. 실패하면 `[!]` 경고만 남기고 다음 단계로 넘어간다.
