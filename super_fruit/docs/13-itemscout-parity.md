상품수는 쇼핑검색 API 가 2026-07-31 종료되어 네이버에서 직접 받을 길이 없다.
아이템스카우트 연관키워드 엑셀을 넣은 날마다 상품수가 한 점씩 쌓인다. 그게 종합차트의 상품수·경쟁강도 선이다.

## 환산의 닻

네이버 추세는 0~100 상대지수다. 한 달 검색수는 "그 숫자를 잰 날 직전 30일" 값이므로
그 30일 창의 지수 합이 그 값이 되게 맞춘다. 9월 숫자면 9월 창, 오늘 받은 숫자면 어제까지 창.

## 호출 비용

키워드 하나를 고르면 HUB 5회(검색추세 1 · 클릭추세 1 · 기기 · 성별 · 연령). 12시간 묶음.
HUB 무료 구간은 각 30,000건/월 → 하루 수백 키워드도 남는다.
검색광고는 키워드 하나에 키워드도구 1회 + 입찰가 2회. 여러 키워드는 5개씩 묶어 부른다.

## 바뀐 화면

- 위 카드 순서: 한 달 검색수 → 상품수·경쟁강도 → 월평균 클릭수 → 광고 클릭률 → 평균 입찰가 1~3위 → 손익분기 전환율
- 키워드 상세: 종합차트(1개월/1년/3년/직접 · 일간/주간/월간 · 검색수/클릭량/상품수/경쟁강도), 성수기 요약, 기기·성별·연령·요일 카드
- 황금키워드 필터: 상품수·경쟁강도 구간, 대표 카테고리, 걸린 조건 칩(×로 풀기)
- 여러 키워드: 쉼표 또는 "여러 개" 칸. 넣은 순서대로 한 표
- 엑셀 분석: 아이템스카우트 엑셀 인식. 계산기 줄 "넣기" → 위 판매 설정(공급가·판매가)에 들어가고 저장됨
- 공급가 비교 탭 삭제 (공급가표는 엑셀 분석에서 본다)

## 띄어쓰기

"홍로 사과" 와 "홍로사과" 는 따로 둔다. 네이버 검색광고는 둘을 같은 키워드로 보므로,
띄어쓴 쪽에 입찰가가 없으면 붙여쓴 쪽의 네이버 값을 보여준다. 합치지 않는다.
