# 22 · 저장된 화면에도 네이버 키워드도구 목록을 그대로 — 신선식품부터 (2026-10-11 밤)

보갬: "추후에는 전부를 할 예정이지만 급한 순서대로 보면 과일, 채소, 농산물, 수산물, 축산물 순이야. 일단 신선식품 위주로 완벽하게 구현해야 된다."

docs/21 에서 연관키워드는 네이버 키워드도구가 주는 목록으로 보기로 했다. PC 실시간에서는 찾을 때마다 네이버에 물으니 그대로 나왔지만,
보갬이 평소 보는 저장된 화면(claude.ai 페이지)에는 수집할 때 그 씨앗에서 나온 식품 키워드만 있어서 밤이 32개로 보였다(네이버는 125개를 준다).

## 한 일

`build-related.mjs` — 신선식품 품목 · 품종 이름을 씨앗으로 키워드도구에 **하나씩** 묻고(씨앗 하나에 한 번) 돌아온 목록을 순서 그대로 적어 둔다.

| 묶음 | 씨앗 | 목록 줄 | 파일 |
|---|---|---|---|
| 1 과일 | 103 | 19,584 | `data-rel-1.js` 0.8 MB |
| 2 채소 | 109 | 17,838 | `data-rel-2.js` 0.9 MB |
| 3 견과 · 쌀/잡곡 · 건과 | 56 | 12,645 | `data-rel-3.js` 0.5 MB |
| 4 수산물 · 건어물 | 105 | 32,260 | `data-rel-4.js` 0.9 MB |
| 5 정육 · 계란 | 69 | 31,158 | `data-rel-5.js` 0.9 MB |
| 합계 | **442** | **113,485** | + `data-relidx.js` (씨앗 → 묶음 번호) |

- 씨앗은 화면의 분류표(`CAT_FRESH` · `CAT_VAR` · `CAT_MAP`)에 있는 품목 · 품종 이름이다. 밤 · 사과 · 한우 · 전복 · 홍로 · 설향 · 굴 · 김 …
- 화면은 씨앗을 찾을 때 그 묶음 파일 하나만 읽는다. 처음 한 번 0.5~0.9 MB.
- 목록에 나온 키워드 가운데 화면 데이터(18,690개)에 없던 것이 22,411개다. 이들은 같은 응답의 검색수 · 클릭 · 클릭률에
  1~3 · 5위 입찰가와 예상 실적(`/estimate/performance-bulk`)을 받아 묶음 파일에 같이 실었다. 목록을 열 때 그 숫자로 줄이 생긴다.
- 검색광고 API 만 쓴다. 씨앗 442회 + 입찰가 · 예상 실적 약 1,400회. API HUB 한도는 쓰지 않는다.
- 다시 받기: `수집단계\26-related.bat` (10분쯤, 3일 안에 받은 목록은 건너뜀). "2 오늘 값으로 갱신" 끝에도 붙였다.

## 화면

- 씨앗을 찾으면 표시줄이 **"네이버 키워드도구 목록 · NAVER 검색광고가 준 그대로 · 준 순서 · 10/11 받아 둔 것"** 으로 바뀌고 네이버가 준 순서로 나온다.
  밤 125 · 사과 672 · 홍로 116 · 샤인머스켓 498 · 고구마 969 · 한우 950 · 전복 509 · 굴 144 · 김 449.
- 화면 데이터에 없던 씨앗 96개(설향 · 후지 · 굴 · 김 · 두부 · 장어 · 한돈 …)도 검색하면 묶음 파일을 읽어 줄을 만든 뒤 찾아 준다.
- 네이버가 몇 개만 주는 씨앗이 있다 — 파인애플 2 · 냉이 2 · 콜리플라워 2 · 토란 3 · 설향 5 (다시 물어 확인함. 받다가 빠진 것이 아니다).
  10개가 안 되면 표시줄에 "네이버가 이 씨앗에는 N개만 준다 — 같은 품목 수집분은 확장 목록에 있다" 고 적는다.
- "확장 목록" = 네이버 목록 + 저장된 같은 품목 수집분(고구마 969 → 1,046, 파인애플 2 → 48). 그 씨앗에서만 켜지고, 다른 씨앗을 찾으면 네이버 목록으로 돌아온다.
- 네이버 목록을 보는 중에 줄을 누르면 **목록은 그대로 두고 위 카드 · 상세만 그 키워드로** 바뀐다. 전에는 누른 키워드의 연관으로 목록이 갈아 끼워졌다.
  그 키워드로 파고들려면 검색을 누른다(검색 칸에 이름이 들어가 있다).
- 받아 둔 목록이 없는 씨앗(공주밤 같은 꼬리 키워드)은 전처럼 수집할 때 나온 연관을 보여 주고 그렇다고 적는다.

## 정직하게 적어 둘 것

- **네이버가 준 그대로라서 식품이 아닌 키워드가 섞여 있다.** 밤 → 바이오힐보필링젤 · 복숭아묘목, 한우 → 진해맛집 · 돈까스, 후지 → 후지필름 · 육절기.
  빼지 않았다(빼면 "네이버가 주는 목록"이 아니게 된다). 구매의도 열과 필터로 거른다.
- **새 키워드 22,411개 가운데 쇼핑 클릭 지수를 아는 것은 5,171개**(있음 1,185 · 0 이 3,986)이고 **17,240개는 "미확인"** 이다(검색 1,000 이상이 3,926개).
  신선식품 칸에 들어가는 1,196개만 HUB 로 받았다(299회). 나머지는 11월 한도로.
- 새 키워드의 대표 카테고리는 글자에서 읽은 것이다. 품목 글자가 우연히 겹쳐 엉뚱한 칸에 든 약 300개를 `CAT_NOT` 등으로 뺐다
  (후지제록스 · 후지필름 → 사과, 타임코트 → 허브, 낚시배 · 수경재배 → 배, 목이물감 → 버섯, 미백치료 → 옥수수, 기장시장 → 잡곡, 타이벡가방 → 감귤, 캠벨생명과학 → 포도, 호매실 → 매실 …).
  맛집 · 낚시 · 효능 · 만드는법 같은 정보 키워드는 화면 데이터와 같은 규칙으로 그 품목 칸에 남는다(쭈꾸미낚시 → 주꾸미). 구매의도 "없음" 으로 걸러진다.
- 품종 이름 가운데 다른 뜻이 더 큰 씨앗이 있다 — 후지 · 신고 · 머스크 · 미백 · 타임 · 팽이 · 아리수. 네이버 목록이 그 다른 뜻으로 채워져 온다. 목록은 그대로 두고 분류만 미분류로 뺐다.
- 김치 · 반찬 · 가공식품 · 건강식품은 아직 받지 않았다. 다음 차례다.
