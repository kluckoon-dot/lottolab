# 21 · 상품수 · 경쟁강도를 빼고 네이버가 주는 지표로 (2026-10-11 밤)

보갬: "연관키워드는 네이버 키워드도구가 주는 것으로 하자. 상품수 · 경쟁강도도 엑셀이 없으면 의미가 없다. 그에 준하는 지표를 네이버가 주는 게 없는지 완벽 검토하고,
없으면 구매 보통 · 높음을 더 강조하자. 광고 클릭률이 높은 키워드를 쓰는 것도 좋겠다. 표는 버릴 것 버리고 놓친 지표는 살려서 정리하자."

docs/20 의 "엑셀이 있으면 아이템스카우트 목록이 먼저" 는 이 결정으로 뒤집혔다. 엑셀 목록은 단추로만 남고, 저장된 화면(아티팩트)에서는 뺐다.

## 놓치고 있던 것: 예상 실적

`/estimate/performance-bulk` 는 (키워드, 기기, 입찰가)를 200개까지 받아 네이버가 추정한 한 달 노출 · 클릭 · 광고비를 준다. 한 번에 0.1초.

```
공주밤 모바일   입찰가 300 → 클릭   738 · 광고비   171,053
               입찰가 350 → 클릭 1,171 · 광고비   310,532   (3위 입찰가)   클릭당 265원
               입찰가 530 → 클릭 2,653 · 광고비 1,022,594   (1위 입찰가)   클릭당 385원
               입찰가 700 → 클릭 2,653 · 광고비 1,323,926   더 올려도 클릭은 그대로
```

여기서 나오는 것:
- **3위 광고 예상 클릭** — 그 자리에 광고를 걸면 한 달에 몇 번 눌리는가. 키워드의 광고 시장 크기다.
- **실제 클릭 단가** = 예상 광고비 ÷ 예상 클릭. 입찰가는 낼 수 있는 상한이고 실제로 나가는 돈은 이쪽이다 (공주밤 350원 → 265원).
- **손익분기 전환율** = 실제 클릭 단가 ÷ 주문 1건 마진. 전에는 3위 입찰가로 내서 실제보다 나쁘게 나왔다 (밤 10.4% → 8.5%).

경쟁강도(상품수 ÷ 검색수)가 재려던 것은 "수요에 비해 파는 사람이 얼마나 몰렸나" 다. 그 결과가 값으로 나타난 것이 경매에서 정해지는 클릭 단가다.
그래서 상품수 대신 **클릭 단가와 그 단가로 얻는 클릭수**를 쓴다. 상품수를 흉내 낸 값은 아니다 — 다른 길로 같은 질문에 답한다.

수집: `refresh-naver.mjs` 의 `perf` 단계 (기본 단계에 넣었다). 키워드마다 모바일 · PC × 3위 · 1위 입찰가 네 건. 41,799개에 836회 · 2.6분.
`fresh.json` 의 `e = [모3클릭, 모3비용, 모3노출, PC3클릭, PC3비용, PC3노출, 모1클릭, 모1비용, PC1클릭, PC1비용]`, 묶음 열 28~37.
화면 18,690개 전부 값이 있고 예상 클릭이 1 이상인 것은 11,450개다. 실시간 서버도 찾을 때마다 같이 받는다.

중간 입찰가 · 최소 노출 입찰가는 받아 봤으나(밤 690 · 1,170원) 쓰지 않는다. 순위별 입찰가와 예상 실적이 같은 것을 더 자세히 말해 준다.

## 표와 필터

| 전 | 지금 |
|---|---|
| 키워드 (구매 알약이 이름 옆에 작게) | 키워드 |
| 월 검색수 | 월 검색수 |
| — | **구매의도** (없음 · 낮음 · 보통 · 높음 + 닭가슴살의 몇 배 · 쇼핑 클릭 지수) |
| 월평균 클릭수 | 월평균 클릭수 |
| 광고 클릭률 (모바일만 크게, PC 작게) | **광고 클릭률** (PC·모바일을 검색수로 가중한 값 + PC / MO 둘 다) · 3% 이상은 초록 |
| 1 · 2 · 3위 입찰가 | 그대로 |
| 광고 깊이 | **경쟁 광고 수** (같은 값. 그 키워드에 함께 뜨는 광고 수, 최대 15) |
| 상품수 | 뺌 |
| 경쟁강도 | 뺌 |
| — | **3위 광고 예상 클릭** (+ 클릭당 실제 단가) |
| 손익분기 전환율 (3위 입찰가 기준) | 손익분기 전환율 (**실제 클릭 단가 기준**) |
| 황금점수 · 판정 | 그대로 (손익분기가 바뀌어 광고 감당 여부가 조금 달라진다) |

필터: 상품수 · 경쟁강도 → **구매의도**(낮음 이상 · 보통 이상 · 높음) · **광고 클릭률**(1 · 2 · 3 · 5% 이상). "아이템스카우트 기준" 프리셋은 뺐다.
머리 카드: 상품수 · 경쟁강도 → "3위로 광고하면 · 네이버 예상". 종합차트의 상품수 · 경쟁강도 단추는 값이 있을 때만 나온다.

## 연관키워드

- PC 실시간: 네이버 키워드도구가 지금 주는 목록 그대로, 준 순서 그대로 (밤 125개 · 2초). 쇼핑 클릭 지수는 검색량 큰 순 120개까지.
- "확장 목록" 단추: 한 겹 더 + 우리 수집본 + 꼬리말 조회 (밤 701개 · 16초). 엑셀을 넣어 둔 씨앗은 "아이템스카우트 엑셀 목록" 단추가 같이 나온다.
- 저장된 화면: 수집할 때 그 씨앗에서 나온 연관 중 화면에 담긴 식품 키워드만 있다(밤 32개). 네이버가 지금 주는 목록 전부가 아니라고 표시줄에 적는다.
  품목별로 네이버 목록을 통째로 실어 두려면 따로 받아야 한다 — 하지 않았다.
