# 29 · 처음 화면은 검색 전 상태 (2026-10-13)

보갬: "항상 디폴트값이 고수로 검색되어 있는 채로 되어 있는데, 디폴트값은 아무것도 없는 키워드 검색 전의 상태가 기본으로 되도록 조정하자!"

## 왜 고수였나

처음 열 때 "지금 기준에서 제일 좋은 키워드"(황금점수 1위)를 대신 골라 머리 카드 · 숫자 카드 · 구매층 · 수익 상자에 채워 넣었다. 그게 고수였다. 검색창에도 그 글자를 적어 넣어, 내가 고수를 검색한 것처럼 보였다.

## 지금

고르지 않은 키워드는 보여 주지 않는다.

| 언제 | 화면 |
|---|---|
| 처음 열었을 때 | 검색창 비어 있음 · 머리 카드 "아직 고른 키워드가 없다" · 숫자 카드와 구매층 숨김 · 표는 전체 목록 |
| 검색창의 × | 검색 전 상태로 돌아간다(전에는 글자만 지웠다). 연관 목록을 보던 중이면 전체 목록으로 |
| 섹션을 바꿀 때 | 검색 전 상태(전에는 그 섹션의 1위 키워드를 대신 골랐다) |
| 검색 · 품목 바로가기 · 표의 줄 · 트렌드/시장 지도에서 고르기 | 그 키워드가 골라진다 |

고른 키워드가 없을 때:

- **수익 상자**는 광고비를 빼지 않은 값(= 광고 전 수익)을 보여 주고 "키워드를 고르면 광고비까지 뺀다" 고 적는다.
- **키워드 상세** 탭은 "아직 고른 키워드가 없다" 안내만 보여 준다.
- **수익 · 광고효율** 탭은 광고비 0 으로 그리고 그렇다고 적는다.
- **상품명 만들기** 는 원래대로 "먼저 검색하라" 안내.
- 표에 고른 줄 표시(초록 바탕)가 없다.

곁들여 고친 것: 연관 목록을 보고 있지 않을 때 표의 줄을 눌러도 고른 줄 표시가 옮겨 가지 않던 것.

## 구현 메모

`NOSEL`(아직 안 골랐다) 깃발 하나를 뒀다. `CUR`(지금 키워드 번호)는 안에서 쓰는 자리가 많아 비우지 않고 그대로 두고, 화면 쪽(`renderHero` · `renderBuy` · `renderDetail` · `renderMargin` · `renderProfit` · 표)이 `NOSEL` 을 보고 빈 상태를 그린다. 키워드를 고르는 자리마다 `NOSEL=false`, 검색 전으로 돌아가는 자리는 `noSel()`.
