# 31 · 매일 수집 — 네이버와 매일 같은 숫자 (2026-10-16)

보갬: "정기적으로 네이버와 동일한 검색값이 나오도록, 일주일에 한 번이든 2주일에 한 번이든 네이버가 업데이트하는 날짜를 기준으로 우리도 같이 업데이트하자." → 로드 추천(매일 + 월요일 입찰가) → "오케이, 그렇게 예약해서 빠짐없이 조사되도록 진행하자!!"

## 네이버는 언제 바꾸나

- 네이버 검색광고가 키워드도구 숫자의 갱신 주기를 밝힌 자료는 찾지 못했다. 소개 글들은 "최근 30일(한 달) 기준" 이라고만 한다.
- 우리 자료로 잰 것: 10/12 값과 10/16 네이버 값 (화면 키워드 1만 7천 개)

| 월 검색수 | 4일 뒤 똑같음 | ±10% 안 |
|---|---|---|
| 100 미만 | 61% | 61% |
| 100~1,000 | 13% | 66% |
| 1,000~1만 | 1% | 77% |
| 1만 이상 | 0% | 81% |

  → 주 · 2주에 한 번 정해진 날에 바뀌는 것이 아니라 날마다 움직인다(최근 30일이 하루씩 밀린다). 같은 날 안에서는 그대로였다 — 10/16 14:32 ~ 22:30 30분마다 60개를 물었을 때 한 번도 안 바뀌었다.
- 하루 중 몇 시에 바뀌는지는 30분마다 재고 있다(probe-naver.mjs · naver-out/probe.ndjson, 10/16 14:32 ~ 10/17 16:40). 결과에 맞춰 예약 시각을 옮긴다.

## 그래서

| 언제 | 무엇 | 파일 |
|---|---|---|
| 매일 07:00 | 품목 씨앗 목록 490개 + 키워드별 목록 약 12,000~13,000개 다시 → 목록 밖 키워드는 다섯 개씩 직접 물음 → 화면 데이터 · 목록 파일 → claude.ai 다시 올림 | 5 매일 수집.bat (약 70분) |
| 월요일 07:00 | 입찰가 · 예상 실적(화면 키워드 전부) · 꼬리 키워드 + 위의 매일 수집 | 4 정기 수집.bat (약 110분) |
| 매달 초 | 쇼핑 클릭 지수 · 추세 · 구매층 (API HUB 한도) | 2 오늘 값으로 갱신.bat · 25-buyers.bat — 사람이 지켜보며 |

- 예약 작업 `keyword-lab-weekly-collect` (이름은 그대로, 매일 07:00). 월요일이면 4, 그 밖의 날은 5 를 돌리고, 끝나면 저장본을 64MB 아래 묶음으로 나눠 올린다.
- 예약 작업은 PC 와 Claude 앱이 켜져 있을 때 돈다. 꺼져 있었으면 다음에 켰을 때 돈다.
- 검색광고 API 만 쓴다. 하루 약 13,500회(목록) + 목록 밖 키워드 수백 회. 10/16 하루에 3만 회 넘게 불렀지만 막힌 적이 없다.

## 목록 밖 키워드 (fetch-stale.mjs)

매일 목록을 다시 받으면 목록에 나오는 키워드는 모두 오늘 값이 된다. 어느 목록에도 안 나오는 키워드(꼬리 키워드로만 찾은 것 · 9월 수집분에만 있는 섹션 키워드)만 남는다 — 10/16 에 1,892개. 이것만 골라 다섯 개씩 그 키워드 그대로 묻고 naver-out/related-stats.ndjson 에 적는다. build-web · naver-latest 가 이 파일도 가장 새 값의 원본으로 읽는다.
매일 수집 끝에 `fetch-stale.mjs --stat` 이 "오늘 값이 아닌 것" 을 센다 — 10/16: 180,553개 중 3개(네이버에 물을 수 없는 형식).

## 주간 입찰가 대상

refresh-naver.mjs 는 9월 수집분 섹션 키워드(section-keywords.txt)만 다시 받았다. 네이버 목록에서 들어온 섹션 키워드(쭈꾸미 …)의 입찰가가 처음 한 번 뒤로 다시 안 받아졌다. build-web 이 화면 키워드 목록(naver-out/screen-keywords.txt)을 떨구고, 4 정기 수집이 그것으로 입찰가 · 예상 실적을 받는다.

## 키워드는 계속 늘어난다

새 씨앗의 목록에서 새 신선식품 키워드가 나오면 다음 날 그것도 씨앗이 된다. 10/16 아침 18,690 → 저녁 섹션 29,398 · 사전 151,155 · 씨앗 13,532. 네이버가 우리 신선식품 씨앗 근처에 띄우는 키워드가 다 들어올 때까지 며칠 더 늘다가 멈출 것이다. 저장본은 지금 80MB 쯤이라 두 번에 나눠 올린다.
