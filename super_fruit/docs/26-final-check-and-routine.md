# 26 · 최종 확인(네이버 · 아이템스카우트 대조)과 정기 수집 (2026-10-12)

보갬: "이제 완성형에 가깝다. 키워드들이 네이버 광고에서 주는 것, 아이템스카우트가 보여 주는 결과와 크게 오류가 날 만큼 문제가 있는지만 최종 확인하고,
이후에는 정기적으로 키워드를 수집하면서 과일 · 채소 다음으로 수산물 → 축산물 → 신선식품 나머지 → 그다음은 요청에 따라 하나씩 정리하자."

## 1. 화면 값 ↔ 지금 네이버 값

화면 키워드 18,690개에서 400개(검색 많은 순 200 + 고르게 200)를 뽑아 검색광고 API 를 지금 다시 불러 맞댔다. 화면 값은 하루 전(10/11) 수집분이다.

| 항목 | 결과 |
|---|---|
| 월평균 클릭수 · 광고 클릭률 · 경쟁 광고 수 · 경쟁정도 | 400개 전부 같음 |
| 월 검색수 | 5% 안 89% · 10% 안 98% · 가장 큰 차이 18% (중앙 1.2%) |
| 모바일 3위 입찰가 | 같음 88% · 전부 10% 안 |

검색수는 네이버가 최근 30일 창을 매일 하루씩 옮겨 주는 값이라 하루 사이에 조금 움직인다. 크게 벌어진 것은 검색 100~500 의 작은 키워드
(10 단위로 주므로 한 칸이 10%)와 추석이 지난 선물 키워드였다. **수집 · 표시 과정에서 생긴 오류는 없다.**

## 2. 아이템스카우트 ↔ 네이버 (보갬이 넣어 둔 엑셀 2개, 받은 날 네이버를 같이 불러 맞댄 것)

| 항목 | 밤 목록 330개 (10/11) |
|---|---|
| 월 검색수 | 10% 안 55% · 20% 안 67% · 중앙 7.1% · 큰 것은 9배 (밤삶는방법 IS 29,200 / 네이버 257,420) |
| 평균 클릭수 | 10% 안 28% · 중앙 21% |
| 모바일 광고단가 ↔ 네이버 5위 평균 입찰가 | 10% 안 91% (docs/16 의 결론 그대로) |

아이템스카우트의 검색수 · 클릭수는 네이버의 지금 값보다 **뒤처진 저장값**으로 보인다(철을 타는 키워드에서 차이가 크다. 광고단가는 잘 맞는다).
화면은 네이버의 지금 값을 쓰므로, 두 화면의 검색수가 다를 때는 화면 쪽이 최신이다.

## 3. 연관 목록 — 여기에 빈 곳이 있었다

씨앗 "밤" 으로 맞대 봤다.

- 네이버 키워드도구가 준 밤 키워드 56개는 **전부** 아이템스카우트 목록에도 있다.
- 아이템스카우트 330개 가운데 밤 글자가 든 것은 143개, 나머지 187개는 x · 에어프라이어 · CJ · 한우 같은 다른 키워드다(아이템스카우트 목록도 섞여 있다).
- 그 143개 가운데 우리 자료(화면 데이터 + 받아 둔 목록)에 있는 것은 69개. **없는 것이 74개**였다.
  - 정보 키워드: 밤삶는방법 · 밤보관법 · 밤찌는법 (구매의도가 없어 넣어도 걸러진다)
  - 밤이 아닌 것: 밤부베베 · 긴긴밤 · 밤켈 · 화장품 ○○밤
  - 도구: 밤까는기계 · 밤가위 · 밤칼
  - **팔 키워드: 26년햇밤(9,400) · 밤1kg(2,600) · 밤시세(1,900) · 밤10kg · 국내산밤 · 특대밤 · 토종밤 · 보늬밤(26,050) · cj맛밤 · 밤만쥬 …**
- 이 말들은 9월에 모은 수집 원본 56만 개에도 없다. 네이버 키워드도구의 "연관" 을 따라가서는 닿지 않는 키워드다(네이버에 검색량은 있다).

### 꼬리 키워드 찾기 — `fetch-tails.mjs`

품목 · 품종 이름 442개에 꼬리말 30개(1kg · 5kg · 가격 · 시세 · 직거래 · 선물세트 · 특대 …)와 머리말 24개(햇 · 26년햇 · 국내산 · 유기농 · 못난이 · 냉동 · 깐 …)를 붙인 후보를
검색광고 API 에 **그 말 그대로** 묻고, 검색량이 30 이상인 것만 받는다(가려진 "< 10" 은 0 으로 센다). 크롤링이 아니라 공식 API 조회다.
밤: 햇밤 13,770 · 26년햇밤 9,330 · 깐밤 7,210 · 밤가격 5,840 · 생밤 4,960 · 꿀밤 3,250 · 밤1KG 2,600 · 밤시세 1,890 · 밤10KG 660 · 국산밤 600 · 토종밤 570 …

`build-related.mjs` 가 네이버 목록에 없던 꼬리 키워드를 품목 씨앗의 목록 뒤에 붙이고(`tails`), 화면은 표시줄에 "꼬리 키워드 N개를 뒤에 붙였다" 고 적는다.

남는 빈 곳: 붙임말로 만들 수 없는 이름(보늬밤 · 밤만쥬 · cj맛밤 · 산지 이름 ○○밤)은 여전히 못 찾는다.
이런 것은 보갬이 그 품목의 아이템스카우트 엑셀을 `넣는곳\아이템스카우트` 에 넣으면 그 키워드들을 네이버에 물어 붙일 수 있다(대량 수집은 하지 않는다).

## 4. 정기 수집

| 주기 | 무엇 | 한도 |
|---|---|---|
| 매주 | `4 정기 수집.bat` — 검색수 · 클릭 · 입찰가 · 예상 실적(화면 키워드 전부) → 꼬리 키워드 → 품목 씨앗 목록 → 키워드별 목록(6일 넘은 것 다시) | 검색광고 API 만. 약 100분 |
| 매달 초 | `2 오늘 값으로 갱신.bat` — 쇼핑 클릭 지수(구매의도) · 3년 추세 | API HUB 약 1만 회 |
| 매달 | `수집단계\25-buyers.bat` — 구매층 | API HUB 9,000회씩 |

- `fetch-related-more.mjs --max-age 6`: 받은 지 6일 넘은 목록만 다시 받는다. 다시 받으면 줄이 쌓이므로 시작할 때 씨앗마다 최신 줄만 남긴다.
- 저장된 화면(claude.ai)은 수집 뒤에 다시 올려야 바뀐다.
