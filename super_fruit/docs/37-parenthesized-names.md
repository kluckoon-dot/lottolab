# 37 · 괄호 이름 정리 (2026-11-25)

보갬: "괄호 이름 46개도 정리해줘"

## 무엇이 문제였나

- 황금키워드 표(섹션)에 `수라향(설국향)`처럼 괄호가 든 키워드가 46개 있었다.
  - 42개: 처음 만든 품종 달력의 별칭 표기. `sections.json` 분류 규칙과 `seeds.json` 씨앗에 괄호째 들어가 있었다.
  - 2개: 산지 표시가 붙은 이름(`영주사과(영주)` · `진도미역(진도)`).
  - 2개: 네이버가 준 회사 · 상품 이름(`완도전복(주)` · `KODEX3대농산물선물(H)` — 뒤의 것은 ETF).
- 네이버는 괄호 표기를 검색 "10 미만"으로만 돌려준다. 실제 검색은 괄호 없이 따로 쓴 이름에 있다(`수라향` 140 · `설국향` 70).
- 그래서 표에는 값이 늘 10으로 보였고, 매일 수집이 다시 물어볼 수도 없었다.

## 고친 것

1. **별칭을 실제 이름 둘로 나눔**
   - 대상: `sections.json` 과일 · 채소 terms, `seeds.json` 1단계 seeds.
   - 예: `수라향(설국향)` → `수라향` · `설국향`.
   - 이미 있는 이름은 다시 넣지 않았다. terms는 523개에서 543개가 됐다.
   - 이름이 아닌 괄호 안 표시는 버렸다: `딱딱` · `말랑`(식감), `-주황`(색).
   - `독활`은 넣지 않았다. 땅두릅의 다른 이름이지만 검색은 한약재(효능 · 기생탕) 쪽이 많다.
2. **제외어에 `(` 추가**
   - 괄호 든 키워드는 섹션에서 섹션 밖 사전으로 옮겼다. 버리지 않았으므로 정확 키워드 검색과 연관 목록에는 그대로 나온다.
3. **받아 둔 적 없던 이름 13개를 네이버에 물어봄**(`fetch-requests.mjs --file`)
   - 12개가 섹션에 들어왔다: 청방배추 1,440 · 백목이 430 · 노란멜론 390 · 불미나리 150 …
   - `곰달비`는 품목을 읽지 못해 섹션 밖 사전으로 갔다.

## 결과

- 섹션은 51,101개에서 51,067개가 됐다(괄호 46개 빠짐, 실제 이름 12개 들어옴). 그 밖의 키워드는 바뀌지 않았다.
- 섹션에 남은 괄호 키워드는 0개다.
- 매일 점검: 실패 0 · 경고 0.
