슈퍼프룻 - 네이버 키워드 수집기
================================

명령어 칠 일 없습니다. 파일을 순서대로 더블클릭만 하세요.


[이 수집기의 원칙]
------------------
키워드에는 옳고 그름이 없습니다.

"샤인머스캣"과 "샤인머스켓"은 서로 다른 시장입니다.
맞춤법이 맞는 쪽만 남기거나, 검색량이 큰 쪽으로 합치거나,
검색량이 적다고 건너뛰는 일을 하지 않습니다.

수집된 모든 키워드가 예외 없이 같은 대접을 받습니다.
월검색수 / 클릭수 / CTR / 경쟁도 / 1~3위 입찰가(PC,모바일) 전부.

검색량이 "< 10" 으로 가려진 키워드도 버리지 않고 담되,
가려진 값이었다는 표시를 함께 남깁니다.


[네이버 API 는 두 종류입니다]
-----------------------------
 A. 검색광고 API   월검색수 / 클릭 / CTR / 경쟁도 / 1~3위 입찰가
 B. NAVER API HUB  3년 주간 추세 / 연령 / 성별 / 기기

서로 다른 서비스라 키도 따로입니다. 둘 다 있어야 화면이 완성됩니다.
입찰가는 A 에서만 나옵니다. B 에는 없습니다.


[수집 우선순위]
---------------
 1단계  과일 · 채소        시드 324개   <- 최우선
 2단계  식품 전체          시드 189개
 3단계  생활 · 건강        시드  83개   <- 여유 있으면
 4단계  여가 · 생활편의     시드  48개

시드 하나를 넣으면 연관 키워드가 수십 개씩 딸려 나옵니다.
그래서 최종 키워드 수는 시드 수의 수십 배가 됩니다.

앞 단계부터 순서대로 처리하고, 입찰가도 앞 단계 키워드부터 먼저 받습니다.


[파일 목록]
-----------
 key.txt                   키를 넣는 곳
 1-check.bat               연결 확인
 2-collect-fruit-veg.bat   1단계 과일 채소
 3-collect-food.bat        2단계 식품 전체
 4-collect-more.bat        3~4단계 생활건강 여가
 5-check-hub.bat           API HUB 연결 확인
 seeds.json                수집 우선순위 목록
 supply-calendar.json      수확 캘린더 202품종


========================================
 설치와 실행
========================================

[준비] Node.js 설치  (한 번만)
------------------------------
https://nodejs.org 접속
"LTS" 라고 적힌 버튼을 받아서 설치
설치 중 선택은 전부 기본값 그대로 [다음]

이미 깔려 있으면 건너뜁니다.
안 깔려 있으면 1-check.bat 이 알려주고 사이트를 열어줍니다.


[1] 압축 풀기
-------------
받은 zip 파일을 우클릭 -> [압축 풀기]
바탕화면이든 문서 폴더든 어디든 상관없습니다.

주의: 압축 안에서 바로 실행하면 안 됩니다. 반드시 풀고 나서 실행하세요.


[2] 검색광고 키 3개 발급
------------------------
1. searchad.naver.com 로그인
2. 우측 상단 [도구] -> [API 사용 관리]
3. [네이버 검색광고 API 서비스 신청]
4. 나오는 값 3개를 복사

   - 액세스라이선스
   - 비밀키        <- 이때 한 번만 보입니다. 놓치면 재발급하세요
   - 고객ID        <- 우측 상단 계정 번호, 숫자


[3] key.txt 에 붙여넣기
-----------------------
key.txt 를 더블클릭하면 메모장으로 열립니다.

  NAVER_AD_API_KEY=여기에 액세스라이선스
  NAVER_AD_SECRET=여기에 비밀키
  NAVER_AD_CUSTOMER=여기에 고객ID 숫자

= 기호 뒤에 바로 붙여넣고 Ctrl+S 로 저장.
따옴표나 띄어쓰기는 신경 안 써도 됩니다.


[4] 1-check.bat 더블클릭
------------------------
검은 창이 뜨고 몇 초 뒤 메모장이 열립니다.

  HTTP 200 이 보이면 성공입니다. 바로 [5] 로 갑니다.
  다른 숫자가 보이면 그 내용을 그대로 보내주세요.

* 검은 창이 깜빡하고 사라지면: 파일 우클릭 -> [열기] 로 실행
* "Windows의 PC 보호" 경고: [추가 정보] -> [실행]


[5] 2-collect-fruit-veg.bat 더블클릭
------------------------------------
1단계 과일 채소를 수집합니다.

수집은 두 단계로 돕니다.
  1단계  시드를 넣고 연관 키워드를 받아옵니다
  2단계  받은 키워드 전부의 1~3위 입찰가를 PC/모바일 따로 받습니다

검은 창을 닫지 마세요. 시간이 꽤 걸립니다.
중간중간 저장되므로 멈추거나 한도에 걸려도
같은 파일을 다시 실행하면 남은 것만 이어서 채웁니다. 처음부터 하지 않습니다.

끝나면  naver-out\keywords.json  이 생깁니다. 그 파일을 보내주세요.


[6] 3-collect-food.bat  (그다음)
--------------------------------
2단계 식품 전체로 넓힙니다. 5번에서 끝난 것은 건너뜁니다.


[7] 4-collect-more.bat  (여유 있으면)
-------------------------------------
3~4단계 생활건강 / 여가생활편의까지 넓힙니다.
앞 단계가 끝났고 호출 한도가 남았을 때만 하세요.


[8] 5-check-hub.bat  (API HUB)
------------------------------
key.txt 아래쪽의 NAVER_HUB_ID / NAVER_HUB_SECRET 를 채운 뒤 실행하세요.

이 프로그램은 호출 주소를 찾아내는 역할입니다.
이관하면서 주소가 바뀌었는데 확정이 안 돼서,
후보를 전부 시도해보고 되는 것을 찾습니다.
결과(hub.txt)를 보내주세요.


[중간에 멈췄을 때]
------------------
그냥 같은 bat 파일을 다시 더블클릭하세요.
"이어하기: 키워드 N개 ... 불러왔다" 가 뜨면 정상입니다.
이미 받은 것은 건너뛰고 남은 것만 채웁니다.


[주의]
------
key.txt 는 남에게 보내지 마세요. 비밀번호와 같습니다.
probe.txt 와 hub.txt 에는 키가 안 찍히게 막아놨습니다. 그대로 보내도 됩니다.
실수로 키가 새어나갔다 싶으면 재발급하면 그만입니다.
