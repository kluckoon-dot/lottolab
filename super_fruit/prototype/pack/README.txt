슈퍼프룻 - 네이버 키워드 수집기
===============================

명령어 칠 일 없습니다. 순서대로 따라만 하세요.


[준비] Node.js 설치  (한 번만)
------------------------------
https://nodejs.org  접속
초록색 버튼 중 "LTS" 쪽을 받아서 설치
설치 중 나오는 선택은 전부 기본값 그대로 [다음]

이미 깔려 있으면 건너뛰세요.
안 깔려 있으면 1-check.bat 이 알려주고 사이트를 열어줍니다.


[1단계] 키 3개 발급
-------------------
1. searchad.naver.com 로그인
2. 우측 상단 [도구] -> [API 사용 관리]
3. [네이버 검색광고 API 서비스 신청] 누르기
4. 화면에 나오는 값 3개를 복사해 둡니다

   - 액세스라이선스
   - 비밀키            <- 이때 한 번만 보입니다. 놓치면 재발급하면 됩니다
   - 고객ID            <- 우측 상단 계정 번호, 숫자


[2단계] key.txt 에 붙여넣기
---------------------------
이 폴더의  key.txt  를 더블클릭 (메모장으로 열립니다)

  NAVER_AD_API_KEY=여기에 액세스라이선스
  NAVER_AD_SECRET=여기에 비밀키
  NAVER_AD_CUSTOMER=여기에 고객ID 숫자

= 기호 뒤에 바로 붙여넣으세요. 따옴표나 띄어쓰기는 신경 안 써도 됩니다.
Ctrl+S 로 저장하고 닫습니다.


[3단계] 1-check.bat 더블클릭
----------------------------
검은 창이 뜨고 몇 초 뒤 메모장이 열립니다.
그 내용 전체를 복사해서 보내주세요.

* 검은 창이 깜빡하고 사라지면: 파일 우클릭 -> [열기] 로 실행
* 창에 빨간 글씨가 보여도 괜찮습니다. 그 내용이 그대로 필요합니다


[4단계] 확인 끝나면 2-collect-40.bat
------------------------------------
3단계 결과를 확인하고 제가 알려드리면 실행하세요.
40개만 먼저 돌려보고, 문제 없으면 3-collect-all.bat 으로 전체를 받습니다.

결과는  naver-out\keywords.json  에 저장됩니다. 그 파일을 보내주세요.


[주의]
------
key.txt 는 남에게 보내지 마세요. 비밀번호와 같습니다.
1-check.bat 이 만드는 probe.txt 에는 키가 안 들어가게 막아놨습니다.
실수로 키가 새어나갔다 싶으면 검색광고에서 재발급하면 그만입니다.
