슈퍼프룻 - 네이버 키워드 수집기
===============================

명령어 칠 일 없습니다. 순서대로 따라만 하세요.


[이 수집기의 원칙]
------------------
키워드에는 옳고 그름이 없습니다.

"샤인머스캣"과 "샤인머스켓"은 서로 다른 시장입니다.
맞춤법이 맞는 쪽만 남기거나, 검색량이 큰 쪽으로 합치거나,
검색량이 적다고 건너뛰는 일을 하지 않습니다.

수집된 모든 키워드가 예외 없이 같은 대접을 받습니다.
월검색수 / 클릭수 / CTR / 경쟁도 / 1~3위 입찰가(PC,모바일) 전부.

검색량이 "< 10" 으로 가려진 키워드도 버리지 않고 담되,
가려진 값이었다는 표시를 함께 남깁니다.


[준비] Node.js 설치  (한 번만)
------------------------------
https://nodejs.org  접속
초록색 버튼 중 "LTS" 쪽을 받아서 설치
설치 중 나오는 선택은 전부 기본값 그대로 [다음]

이미 깔려 있으면 건너뛰세요.
안 깔려 있으면 1-check.bat 이 알려주고 사이트를 열어줍니다.


[1단계] 키 3개 발급
-------------------
1. searchad.naver.com 로그인
2. 우측 상단 [도구] -> [API 사용 관리]
3. [네이버 검색광고 API 서비스 신청] 누르기
4. 화면에 나오는 값 3개를 복사해 둡니다

   - 액세스라이선스
   - 비밀키            <- 이때 한 번만 보입니다. 놓치면 재발급하면 됩니다
   - 고객ID            <- 우측 상단 계정 번호, 숫자


[2단계] key.txt 에 붙여넣기
---------------------------
이 폴더의  key.txt  를 더블클릭 (메모장으로 열립니다)

  NAVER_AD_API_KEY=여기에 액세스라이선스
  NAVER_AD_SECRET=여기에 비밀키
  NAVER_AD_CUSTOMER=여기에 고객ID 숫자

= 기호 뒤에 바로 붙여넣으세요. 따옴표나 띄어쓰기는 신경 안 써도 됩니다.
Ctrl+S 로 저장하고 닫습니다.


[3단계] 1-check.bat 더블클릭
----------------------------
검은 창이 뜨고 몇 초 뒤 메모장이 열립니다.
그 내용 전체를 복사해서 보내주세요.

* 검은 창이 깜빡하고 사라지면: 파일 우클릭 -> [열기] 로 실행
* 창에 빨간 글씨가 보여도 괜찮습니다. 그 내용이 그대로 필요합니다


[4단계] 2-collect-40.bat  (40품종 먼저, 3분)
--------------------------------------------
수집은 두 단계로 돕니다.

 1단계  품종 이름을 넣고 "연관 키워드"를 받아옵니다
        품종 하나당 수십 개씩 딸려 나옵니다
 2단계  검색량이 1,000 이상인 키워드만 골라서
        1~3위 입찰가를 PC/모바일 따로 받아옵니다

검은 창을 닫지 마세요. 중간중간 저장되므로 멈춰도 다시 돌리면 됩니다.

결과는  naver-out\keywords.json  에 저장됩니다. 그 파일을 보내주세요.


[5단계] 3-collect-all.bat  (202품종 전체)
-----------------------------------------
40개 결과가 멀쩡하면 전체를 받습니다.

키워드를 하나도 빼지 않고 입찰가까지 받기 때문에
분량에 따라 시간이 꽤 걸립니다.

중간중간 저장되므로, 도중에 멈추거나 하루 호출 한도에 걸려도
같은 파일을 다시 실행하면 "이어하기"로 남은 것만 채웁니다.
처음부터 다시 하지 않습니다.


[만약 "Auth Failed" 가 나오면]
--------------------------------
네트워크는 뚫린 겁니다. 네이버 서버가 직접 준 답이에요.
키 세 값 중 뭔가가 안 맞는 것뿐입니다.

1-check.bat 이 알아서 조합 6가지를 시도하고 원인을 찍어줍니다.
그 내용을 그대로 보내주세요.

가장 흔한 원인 순서:

 1) 고객ID 를 잘못 넣음  <- 제일 많습니다
    검색광고 화면 우측 상단 [내 정보] 옆에 있는 "숫자"입니다.
    네이버 아이디 아닙니다. 사업자등록번호 아닙니다.

 2) 액세스라이선스와 비밀키를 서로 바꿔 넣음
    둘 다 긴 문자열이라 헷갈립니다. 프로그램이 바꿔서도 시도해봅니다.

 3) 비밀키를 못 받음
    비밀키는 발급 순간 한 번만 보입니다. 그때 복사 못 했으면 못 씁니다.
    [도구] -> [API 사용 관리] 에서 다시 발급받고,
    그 자리에서 액세스라이선스와 비밀키를 "둘 다" 복사하세요.

 4) 계정이 다름
    키를 발급한 그 계정의 고객ID 여야 합니다.

 5) 붙여넣다가 줄바꿈이 들어감
    key.txt 에서 = 뒤에 값만, 한 줄로 있어야 합니다.


[주의]
------
key.txt 는 남에게 보내지 마세요. 비밀번호와 같습니다.
1-check.bat 이 만드는 probe.txt 에는 키가 안 들어가게 막아놨습니다.
실수로 키가 새어나갔다 싶으면 검색광고에서 재발급하면 그만입니다.
