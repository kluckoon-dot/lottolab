슈퍼프룻 키워드랩 — 폴더 안내
==============================

평소에는 이 세 개만 씁니다.

  1 키워드랩 열기.bat          화면을 엽니다. 검색하면 네이버 지금 값을 받아옵니다.
  2 오늘 값으로 갱신.bat        화면 키워드 전부를 오늘 값으로 다시 받습니다 (35분쯤).
  3 아이템스카우트 대조.bat      넣는곳\아이템스카우트 의 엑셀을 네이버 지금 값과 열마다 비교합니다.


[넣는곳]  ← 내려받은 엑셀을 여기로 옮겨주세요
-----------------------------------------------
  넣는곳\아이템스카우트       아이템스카우트 연관키워드 엑셀
                              상품수 · 경쟁강도 · 대표 카테고리가 화면에 붙습니다.
  넣는곳\네이버키워드도구     네이버 검색광고 > 도구 > 키워드도구 에서 받은 엑셀
  넣는곳\공급가표·계산기      공급가 비교표 · 판매가 계산기 엑셀
                              판매가 계산기를 넣으면 수수료율(네이버 · 쿠팡) · 광고 안전계수 · 목표 ROAS 와
                              옵션별 총원가 · 판매가가 위 '판매 설정' 에 연결됩니다. '계산기' 칸에서 옵션을 고르세요.
                              저장된 화면(claude.ai)에 실으려면 app 폴더에서  node build-calc.mjs  (data-calc.js 가 생깁니다)

  "1 키워드랩 열기" 를 누를 때마다 새로 들어온 파일만 자동으로 읽습니다.
  화면에 끌어다 놓지 않아도 됩니다. 이미 읽은 파일은 다시 읽지 않습니다.
  파일 이름은 바꾸지 마세요. 아이템스카우트·키워드도구는 이름 안의 날짜로 기준 시각을 잡습니다.


[손대지 않는 곳]
----------------
  key.txt         네이버 키. 남에게 보내지 마세요.
  naver-out\      받은 데이터 전부 (키워드 · 추세 · 오늘 값 · 대조 결과)
  app\            화면과 프로그램
  수집단계\        처음 수집할 때 쓰던 1~23단계 bat 과 긴 설명서(README.txt). 지금은 거의 안 씁니다.
  기록\            예전 진단 결과와 정리하면서 옮겨둔 파일. 지워도 되지만 남겨뒀습니다.

[25단계 · 구매층 이어받기]
--------------------------
  수집단계\25-buyers.bat
  저장된 화면(claude.ai 페이지)에 쓰는 쇼핑 구매층을 더 받습니다.
  요일별 클릭은 전부 받아 두었고, 기기 · 성별 · 연령은 구매로 이어지는 검색이 큰 키워드부터 받습니다.
  API HUB 쇼핑인사이트가 한 달 5만 회라서 한 번에 9,000회까지만 씁니다. 멈춘 자리에서 이어 받으니
  달이 바뀌면 한 번씩 누르면 됩니다. PC 에서 "1 키워드랩 열기" 로 볼 때는 고르는 키워드마다 바로 받아오므로 이 단계가 없어도 됩니다.

[26단계 · 네이버 연관 목록 받아 두기]
------------------------------------
  수집단계\26-related.bat
  저장된 화면(claude.ai 페이지)에서도 연관키워드를 네이버 키워드도구가 주는 목록 그대로 보려고 받아 두는 단계입니다.
  신선식품 품목 · 품종 이름 약 440개를 하나씩 키워드도구에 묻습니다 (과일 → 채소 → 견과 · 쌀/잡곡 · 건과 → 수산물 · 건어물 → 정육 · 계란).
  검색광고 키만 씁니다. API HUB 한도는 쓰지 않습니다. 10분쯤 걸리고, 3일 안에 받은 목록은 건너뜁니다.
  "2 오늘 값으로 갱신" 을 누르면 끝에 이 단계도 같이 돕니다. PC 에서 "1 키워드랩 열기" 로 볼 때는 찾을 때마다 네이버에 바로 묻습니다.

[27단계 · 키워드마다 네이버 연관 목록 받아 두기]
------------------------------------------------
  수집단계\27-related-more.bat
  26단계는 품목 이름 약 440개만 묻습니다. 이 단계는 화면의 신선식품 키워드(월 검색 100 이상, 약 7,000개)를 하나씩 키워드도구에 묻습니다.
  감홍사과 · 홍천사과처럼 품목 이름이 아닌 키워드를 찾아도 네이버가 주는 목록이 나오게 하려는 것입니다.
  받은 목록에서 품목이 다른 키워드(사과를 찾았는데 오이 · 양상추)는 빼고 싣습니다. 35분쯤 걸리고 검색광고 키만 씁니다.
