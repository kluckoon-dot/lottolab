업데이트용 파일입니다
=====================

기존에 쓰던 폴더에 그대로 덮어쓰세요.

key.txt 는 일부러 뺐습니다.
키가 들어있는 기존 key.txt 를 지우지 않기 위해서입니다.
naver-out 폴더도 들어있지 않으므로 수집한 데이터는 그대로 남습니다.


[하는 법]
---------
1. 이 폴더의 파일을 전부 선택  (Ctrl+A)
2. 복사                        (Ctrl+C)
3. 기존 수집기 폴더로 이동
4. 붙여넣기                    (Ctrl+V)
5. "대상 폴더에 같은 이름의 파일이 있습니다" 가 뜨면
   [파일 덮어쓰기] 선택


[덮어쓴 뒤]
-----------
폴더 안이 이렇게 되어 있으면 정상입니다.

  key.txt            <- 기존 것 그대로 (키 들어있음)
  naver-out\         <- 기존 것 그대로 (13,662개 들어있음)
  6-raw-check.bat    <- 새로 생김
  나머지 파일들        <- 새 것으로 바뀜


[그다음]
--------
6-raw-check.bat  더블클릭  (1분)
  씨앗을 네이버한테 직접 받을 수 있는지 확인합니다
  결과 raw.txt 를 보내주세요

2-collect-fruit-veg.bat  더블클릭
  "이어하기: 키워드 13,662개 ... 불러왔다" 가 뜨면 정상입니다
  새로 추가된 시드 199개와 눈덩이 확장만 돌립니다
  이미 받은 13,662개는 건드리지 않습니다
