슈퍼프룻 - 네이버 키워드 수집기
================================

명령어 칠 일 없습니다. 파일을 순서대로 더블클릭만 하세요.


[이 수집기의 원칙]
------------------
키워드에는 옳고 그름이 없습니다.

"샤인머스캣"과 "샤인머스켓"은 서로 다른 시장입니다.
맞춤법이 맞는 쪽만 남기거나, 검색량이 큰 쪽으로 합치거나,
검색량이 적다고 건너뛰는 일을 하지 않습니다.

수집된 모든 키워드가 예외 없이 같은 대접을 받습니다.
월검색수 / 클릭수 / CTR / 경쟁도 / 1~3위 입찰가(PC,모바일) 전부.

검색량이 "< 10" 으로 가려진 키워드도 버리지 않고 담되,
가려진 값이었다는 표시를 함께 남깁니다.


[네이버 API 는 두 종류입니다]
-----------------------------
 A. 검색광고 API   월검색수 / 클릭 / CTR / 경쟁도 / 1~3위 입찰가
 B. NAVER API HUB  3년 주간 추세 / 연령 / 성별 / 기기

서로 다른 서비스라 키도 따로입니다. 둘 다 있어야 화면이 완성됩니다.
입찰가는 A 에서만 나옵니다. B 에는 없습니다.


[수집 우선순위]
---------------
 1단계  과일 · 채소        시드 523개   <- 최우선
 2단계  식품 전체          시드 189개
 3단계  생활 · 건강        시드  83개   <- 여유 있으면
 4단계  여가 · 생활편의     시드  48개

앞 단계부터 순서대로 처리하고, 입찰가도 앞 단계 키워드부터 먼저 받습니다.


[시드 목록이 전부가 아닙니다 - 눈덩이 확장]
-------------------------------------------
시드는 출발점일 뿐입니다.

 1) 시드를 넣으면 네이버가 연관 키워드를 수십 개씩 돌려줍니다
 2) 그렇게 찾아낸 키워드를 "다시 힌트로" 넣습니다
 3) 또 새로운 키워드가 나옵니다
 4) 기본 2바퀴 반복합니다

사람이 손으로 적은 목록은 반드시 빠지는 게 생깁니다.
그래서 빠진 가지를 눈덩이 확장으로 메웁니다.

시드 523개로 시작해도 최종 키워드는 수만 개가 됩니다.

 key.txt                   키를 넣는 곳

 3-collect-food.bat        2단계 식품 전체
 4-collect-more.bat        3~4단계 생활건강 여가

========================================
 설치와 실행
========================================

[준비] Node.js 설치  (한 번만)
------------------------------
https://nodejs.org 접속
"LTS" 라고 적힌 버튼을 받아서 설치
설치 중 선택은 전부 기본값 그대로 [다음]

이미 깔려 있으면 건너뜁니다.
안 깔려 있으면 1-check.bat 이 알려주고 사이트를 열어줍니다.


[1] 압축 풀기
-------------
받은 zip 파일을 우클릭 -> [압축 풀기]
바탕화면이든 문서 폴더든 어디든 상관없습니다.

주의: 압축 안에서 바로 실행하면 안 됩니다. 반드시 풀고 나서 실행하세요.


[2] 검색광고 키 3개 발급
------------------------
1. searchad.naver.com 로그인
2. 우측 상단 [도구] -> [API 사용 관리]
3. [네이버 검색광고 API 서비스 신청]
4. 나오는 값 3개를 복사

   - 액세스라이선스
   - 비밀키        <- 이때 한 번만 보입니다. 놓치면 재발급하세요
   - 고객ID        <- 우측 상단 계정 번호, 숫자


[3] key.txt 에 붙여넣기
-----------------------
key.txt 를 더블클릭하면 메모장으로 열립니다.

  NAVER_AD_API_KEY=여기에 액세스라이선스
  NAVER_AD_SECRET=여기에 비밀키
  NAVER_AD_CUSTOMER=여기에 고객ID 숫자

= 기호 뒤에 바로 붙여넣고 Ctrl+S 로 저장.
따옴표나 띄어쓰기는 신경 안 써도 됩니다.


[4] 1-check.bat 더블클릭
------------------------
검은 창이 뜨고 몇 초 뒤 메모장이 열립니다.

  HTTP 200 이 보이면 성공입니다. 바로 [5] 로 갑니다.
  다른 숫자가 보이면 그 내용을 그대로 보내주세요.

* 검은 창이 깜빡하고 사라지면: 파일 우클릭 -> [열기] 로 실행
* "Windows의 PC 보호" 경고: [추가 정보] -> [실행]


[5] 2-collect-fruit-veg.bat 더블클릭
------------------------------------
1단계 과일 채소를 수집합니다.

수집은 두 단계로 돕니다.
  1단계  시드를 넣고 연관 키워드를 받아옵니다
  2단계  받은 키워드 전부의 1~3위 입찰가를 PC/모바일 따로 받습니다

검은 창을 닫지 마세요. 시간이 꽤 걸립니다.
중간중간 저장되므로 멈추거나 한도에 걸려도
같은 파일을 다시 실행하면 남은 것만 이어서 채웁니다. 처음부터 하지 않습니다.

끝나면  naver-out\keywords.json  이 생깁니다. 그 파일을 보내주세요.


[6] 3-collect-food.bat  (그다음)

[10단계] 10-check-cat.bat  (카테고리 ID 확인 + 정체 확인)
--------------------------------------------
/categories 는 "목록 조회"가 아닙니다.
내가 넣은 카테고리 ID 를 그대로 돌려주는 "분야별 트렌드"입니다.
그래서 트리를 통째로 받아올 수는 없습니다.

1) 살아있는지: 후보 ID 를 하나씩 때려봅니다.
   data 가 비어 있으면 그런 카테고리가 없다는 뜻입니다.
   없는 번호(59999999)를 대조군으로 섞어놨습니다.
   2026-09-11 확인 결과 대조군이 '없음'으로 나와, 이 검사는 유효합니다.

2) 정체가 뭔지: 살아있다고 그게 '과일'이라는 보장은 없습니다.
   응답의 title 은 제가 적어 보낸 이름을 되돌려주는 것뿐이라 이름 확인이 안 됩니다.
   그래서 그 카테고리 안에 특정 키워드가 실제로 있는지를 물어봅니다.
   사과는 되고 립스틱은 안 되면 그건 과일 쪽입니다.

호출 약 90회. 1분 안 걸립니다.
화면에 나온 표를 통째로 보내주세요.


[12단계] 12-scan-cat.bat  (식품 하위 ID 훑기)

[11단계] 11-collect-shop.bat  (기기 · 성별 · 연령)

10단계를 먼저 돌리세요.

쇼핑인사이트 무료 구간이 월 30,000회라서 27,000회에서 스스로 멈춥니다.

멈춰도 다시 실행하면 이어서 받습니다.
받다 만 키워드는 안 받은 항목만 채웁니다. 이미 받은 건 다시 안 부릅니다.

결과는  naver-out\shop.json  입니다. 그 파일을 보내주세요.

[15단계] 15-shop-fix.bat  (빈 키워드 제자리 찾기)
--------------------------------------------
빈 응답이 나온 이유는 간단합니다.
전부 식품(50000006)으로만 물어봤는데, 그 키워드들이 식품이 아니었습니다.

  밥솥            -> 디지털/가전
  탈모샴푸         -> 생활/건강
  싸이벡스제로나T    -> 출산/육아
  별내맛집 · 진안마이산 -> 쇼핑 키워드가 아님 (맛집 · 지명)

이 단계는 1차 카테고리 8개를 키워드마다 훑어서 데이터가 나오는 첫 자리를
그 키워드의 소속으로 봅니다. 찾으면 거기서 성별 · 연령을 다시 받습니다.
어디에도 없으면 표시해두고 다시 묻지 않습니다.

키워드를 버리지 않습니다. 제자리를 찾아줄 뿐입니다.


[11단계가 바뀌었습니다]
--------------------------------------------
검색량 순으로만 자르니 밥솥 · 탈모샴푸 같은 게 상위 3,000개에 들어왔습니다.
이제 씨앗(과일·채소 -> 식품 전체) 순으로 앞뒤를 가릅니다.

키워드를 버리는 게 아닙니다. 순서만 바꿉니다.
뒤로 밀린 키워드도 예산이 남으면 그대로 받습니다.

  --tiers 1      과일·채소만 앞으로
  --tiers 1,2    과일·채소 + 식품 전체 (기본값)
  --tiers 1,2,3,4  전부

한 글자 씨앗(감 무 배 귤 밤 마 쑥 딜)은 자리를 봅니다.
그냥 빼버리면 배·나주배·햇배·금귤·풋귤·공주밤·햇밤 같은 진짜 품목이
통째로 뒤로 밀립니다. 실제 키워드로 세어보고 확인했습니다.

  그 자체           배, 귤, 밤
  끝에 올 때         나주배, 공주밤, 옥광밤, 풋귤
  앞이면서 4자 이하    배가격, 귤청, 마효능, 배도매

길이를 안 걸면 마스카포네치즈 · 감기에좋은음식 · 마피아게임까지 딸려옵니다.
그래도 포포나무 · 장마 · 마가린 같은 가짜가 100개쯤 남습니다. 그냥 둡니다.
순서를 매기는 일일 뿐이고, 가짜는 식품에서 빈 응답으로 나온 뒤
15단계가 제 카테고리를 찾아줍니다. 버려지는 키워드는 없습니다.
